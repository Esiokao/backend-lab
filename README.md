# Backend Lab

Hands-on backend engineering learning project.

- **Backend Security** — JWT, RBAC, rate limiting, HTTPS/TLS, security headers, DB least privilege, reverse proxy
- **Database** — PostgreSQL, SQLAlchemy, transactions, indexing, query optimization, Alembic
- **Testing** — pytest, integration testing, security regression testing
- **CI/CD & DevOps** — Docker, GitHub Actions, automated testing and migrations

## Tech Stack So Far

Python · FastAPI · PostgreSQL · SQLAlchemy · Alembic · Redis · Docker · Nginx · pytest · GitHub Actions
